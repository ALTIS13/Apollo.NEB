# Apollo.NEB Desktop

Нативный обзор локальной панели для Windows x64. Приложение читает открытые агрегаты панели и даёт перейти к ней в браузере. Порт по умолчанию — 18763. При явно настроенном другом порте введите его в разделе «Подключение» и нажмите «Обновить». При запуске из ярлыка можно передать числовой порт через --port.

Локальную сводку приложение читает по HTTP на 127.0.0.1 и проверяет размер и схему ответа. За непрочитанными датчиками остаётся «—». При потере связи на экране видны время и значения последнего замера.

«GPU этого ПК» показывает датчики отдельно от сводки панели. Данные берутся из одноразового запроса установленного NVIDIA SMI из System32 или Program Files. Показаны PCI-адрес, температура, загрузка, занятая и общая VRAM и мощность. Блок обновляется каждые 10 секунд и доступен, когда локальный API панели выключен.

## Связь с HTTPS-панелью

В разделе «Связь с HTTPS-панелью» укажите её адрес и вставьте одноразовый ключ целиком из раздела «Ноды». Отметьте согласие на передачу показаний и нажмите «Привязать ПК». Успешная привязка подтверждается после первой отправки и проверки связи. При сбое повторите попытку с тем же ключом. Windows хранит ключ ноды в защищённом хранилище текущего пользователя.

Приложение передаёт модель и PCI-адрес NVIDIA GPU, доступные датчики и версию Desktop. Закрытие окна прекращает передачу. Сохранённая привязка возобновляет её при следующем запуске. Кнопка «Удалить ключ на этом ПК» снимает локальную привязку. Для отзыва ключа выберите ноду в разделе «Ноды» самой панели.

## Лимит мощности NVIDIA

Свежий замер GPU может содержать текущий, минимальный и максимальный лимит мощности. В Windows возможность изменения выключена по умолчанию. В привязанном приложении, уже открытом с правами администратора, отметьте разрешение на эту сессию. Выключение разрешения останавливает новые команды. Уже переданная драйверу команда будет проверена по показаниям. При закрытии окна разрешение сбрасывается.

Панель получает подтверждение после повторного чтения лимита. При недоступном результате Windows показывает, что команда осталась неподтверждённой. Для обычных показаний GPU подходит панель с прежним форматом телеметрии.

## Сборка и проверка

Для обычной сборки понадобятся .NET SDK 8, Windows 10 2004 или новее и доступ к NuGet. Для её запуска нужны .NET 8 x64 и полный каталог сборки. Windows App SDK 2.7.0 копируется рядом с exe.

В PowerShell из корня репозитория:

```powershell
dotnet build .\windows\Apollo.NEB.Desktop\Apollo.NEB.Desktop.csproj -c Release
dotnet run --project .\windows\Apollo.NEB.Desktop\smoke\Apollo.NEB.Desktop.Smoke.csproj
```

Тестовый источник динамически выделяет порт на loopback и проверяет штатный запрос, метрики, отсутствующие датчики, предел ответа, отказ от редиректа и разбор NVIDIA CSV с отсутствующими показаниями. Для проверки окна стартуйте локальную панель и запустите собранное приложение.

## Локальный ZIP

Для сборки ZIP используйте .NET SDK 8.0.428, Python 3.10+ и доступ к NuGet. Скрипт читает версию из `neb_release.py`, восстанавливает зафиксированные пакеты и публикует Release `win-x64` в новый каталог.

```powershell
python .\windows\Apollo.NEB.Desktop\package_windows.py --output-dir "$env:TEMP\apollo-neb-packages"
```

Файл `.zip.sha256` содержит SHA-256 и имя архива. Сверьте сумму через `Get-FileHash -Algorithm SHA256`, распакуйте весь ZIP и запустите `Apollo.NEB.Desktop.exe`. Кандидат содержит .NET Runtime 8.0.34 и Windows App SDK 2.7.0 рядом с приложением. Для показаний GPU нужен установленный драйвер NVIDIA с `nvidia-smi`.
