# Apollo.NEB 0.9.0

Стабильный выпуск для основного канала обновлений. В панели видны установленная
версия, совместимый пакет и его SHA-256.

| Пакет | Для чего |
| --- | --- |
| Linux Portable | Локальная добыча NEB Mainnet |
| Linux x64, ядра 6.6 и 6.12 | Отдельные архивы для этих веток ядра |
| Windows x64 | Управление Linux-нодами, Python 3.10+ x64 |

Linux поддерживает AMD/OpenCL, NVIDIA/CUDA и совместимые майнеры с ручной
настройкой. В WSL2 панель определяет NVIDIA через драйвер Windows и использует
доступный датчик температуры для защиты воркера.

**DevFee — 1,1% активного времени добычи.** Состояние видно в панели.
