# Apollo.NEB 0.8.0-rc.1 · Linux Portable

Предварительный выпуск самостоятельной панели добычи NEB Mainnet.

- Обзор и карточки воркеров показывают текущие температуры целыми градусами и стрелками тренда.
- История за 31 день включает график с указателем, температурные пороги, метки термозащиты, запуска панели и перезагрузки хоста.
- Журнал воркера обновляется автоматически. Экран `/view` показывает сводные метрики без входа.
- Блок Mainnet показывает высоту блока и валовую оценку NEB за сутки по локальным замерам и данным Suprnova.
- Резервные коды 2FA скачиваются из панели в Markdown.

**DevFee — 1,1% активного времени добычи.** В панели видны активное окно, пауза владельца и недоступность сервиса.

Установите `apollo-neb-0.8.0-linux.tar.gz` после проверки файла `.sha256`. Для обновления и отката используйте [инструкцию](https://github.com/ALTIS13/Apollo.NEB/blob/main/docs/onboarding-and-distribution.md).

Установка и управление процессами проверены на изолированном Linux с тестовым воркером. Физические GPU и выплаты пула требуют отдельной проверки.
