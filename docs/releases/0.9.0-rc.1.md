# Apollo.NEB 0.9.0-rc.1

Первый предварительный выпуск двух каналов обновлений. В панели выберите
**Основной** или **Тестовый** и проверьте версию, пакет и SHA-256.
Установка выполняется по вашей команде.

| Пакет | Для чего |
| --- | --- |
| Linux Portable | Локальная добыча, AMD/OpenCL и NVIDIA/CUDA |
| Linux x64, ядро 6.6 | Установка на ветке ядра 6.6 |
| Linux x64, ядро 6.12 | Установка на ветке ядра 6.12 |
| Windows x64 | Контроллер Linux-нод, Python 3.10+ x64 |

Сверьте SHA-256 перед распаковкой. На Linux запустите ./install.sh --run.
На Windows откройте Apollo.NEB.cmd и подключите Linux-ноду через **Ноды**.

**DevFee — 1,1% активного времени добычи.** Состояние видно в панели.

[Установка, подключение нод и откат](https://github.com/ALTIS13/Apollo.NEB/blob/main/docs/onboarding-and-distribution.md)
