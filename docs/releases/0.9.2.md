# Apollo.NEB 0.9.2

Общая панель для GPU-фермы и самостоятельных установок NEB Mainnet.

- **Обзор** сводит хешрейт, питание и состояние нод. История показывает
  температурные пороги и события, а GPU сгруппированы по нодам.
- Гостю доступны текущие метрики. Пароль и 2FA открывают управление.
  Резервные коды 2FA можно скачать в Markdown.
- В **Нодах** можно привязать воркер по ключу или установить агент на
  подготовленный Linux-хост по SSH. Для обновления доступны совместимая
  версия, её изменения и статус установки. При сбое запуска возвращается
  предыдущая сборка.
- **Apollo.NEB Desktop** для Windows x64 показывает датчики NVIDIA.
  Подключите его к своей HTTPS-панели по ключу, чтобы видеть ПК в списке нод.

Для Linux доступны обычный архив, пакеты x64 для ядер 6.6 и 6.12
и образы x64 UEFI. Для Windows x64 выберите Desktop или контроллер Linux-нод.
Сверьте SHA-256 выбранного файла перед установкой.

**DevFee составляет 1,1% активного времени добычи.** Состояние видно в панели.
