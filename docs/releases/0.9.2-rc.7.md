# Apollo.NEB 0.9.2-rc.7

Предварительный выпуск для тестового канала.

- Гостевой обзор показывает общую сводку фермы. Пароль и второй фактор
  открывают управление.
- Раздел **Ноды** объединяет GPU и показатели подключённых хостов.
  Подготовленную Linux-ноду можно установить из панели по SSH.
- Для обновления ноды выберите совместимую версию и посмотрите список
  изменений. После сбоя запуска нода возвращает прежнюю сборку.
- Apollo.NEB Desktop для Windows x64 показывает датчики NVIDIA и может
  передавать их в вашу панель после привязки по ключу.

**DevFee составляет 1,1% активного времени добычи.** Состояние видно в панели.
