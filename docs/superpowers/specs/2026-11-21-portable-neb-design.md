# Portable Apollo.NEB 0.6

Из Atlas сохраняем модель панели: сводка, график и история, явные действия
по воркеру, температурная защита и видимая причина остановки. Частные
настройки, адреса, ключи, бинарники и привилегированное управление Vega
остаются на Atlas. Установка на Atlas не выполняется.

Рассмотрены копирование текущей службы с root и перенос в контейнер с
пробросом GPU. Выбрана установка в каталог пользователя Linux: она
не меняет драйверы, сервисы других пользователей или сетевой экран.
Система использует установленные оператором драйверы и доверенный майнер,
без выполнения shell-шаблонов. Встроенные профили Suprminer OpenCL/CUDA и
документированный custom-адаптер разделяют интерфейс панели и алгоритм
майнера. Управление электропитанием карт из этой установки не предусмотрено.

По умолчанию: loopback, пароль администратора, ноль запущенных майнеров,
ноль комиссии. GUI разрешает только явно настроенные воркеры. Для GPU
выбран подтверждённый PCI-адрес с доступной температурой; отсутствие
телеметрии не считается нормой. Дочерние процессы ограничены правами
выделенного пользователя Linux, а не аппаратной изоляцией Atlas.

NEB-пулу передаётся публичный адрес. Приватные ключи не нужны.
Опциональная поддержка автора выделяет явно согласованную долю рабочего
времени, не вычитает монеты из выплат и не подменяет адрес незаметно.
Без подтверждённого получателя сборка никому ничего не начисляет.

Проверка: чистая установка из архива под Linux без sudo, работа
управления и защиты на тестовой нагрузке, HTTPS/SSH рекомендации и
явная таблица различий между стендом, Atlas и физическими GPU сторонних
пользователей.
