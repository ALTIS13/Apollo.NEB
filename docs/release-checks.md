# Проверка Portable

- Запустите python -B -m unittest -v и проверьте синтаксис web/*.js через node --check.
- Откройте панель при ширине 390 и 1366 px. Проверьте каналы обновлений, версию и
  пакет для ОС, ошибки каталога, ещё не опубликованный канал и отсутствие отката
  при переключении с более новой тестовой сборки на основной.
- Проверьте точные Linux-архивы на заявленных ядрах через qa/smoke_linux.py.
  Проверьте остановленный переход на новый тег и восстановление прежнего снимка.
- Проверьте Windows ZIP на нативном Windows x64 через qa/smoke_windows_controller.py,
  в том числе вход, 2FA и сценарий подключения Linux-ноды.
- Проверьте график, целые градусы и стрелки тренда, журнал воркера, экран /view
  и скачивание резервных кодов. Для DevFee проверьте простой, паузу, недоступность
  политики и остановку по термозащите на отдельном стенде.
- Прогон с тестовым процессом подтверждает установку и управление. Физические GPU,
  Mainnet-шары и выплаты проверяются отдельно.
- Публикуйте пакет и его SHA-256 в официальном выпуске. Проверьте, что публичные
  пакеты содержат пользовательский мониторинг DevFee без управления политикой
  владельца. Сохраняйте оригинальные архивы прошлых выпусков и атрибуцию компонентов.

## Сборка официального выпуска

Соберите все платформы с одного проверенного коммита. Повторите команду для
целей linux, linux-6.6, linux-6.12 и windows-x64.

~~~powershell
python -B qa/package_release.py --target windows-x64 --commit COMMIT --output release
~~~

После публикации сверенных файлов обновите резервный публичный OTA-каталог
командой python -B qa/rebuild_ota_catalog.py --output docs/ota-catalog.json.
Каталог содержит только опубликованные пакеты и SHA-256 из GitHub Releases.
