# Проверка Portable

- `python3 -B -m unittest -v` — тесты конфигурации, HTTP и владения
  тестовым дочерним процессом. На Windows Linux-only сценарии пропускаются.
- Проверьте синтаксис JavaScript командой `node --check` для файлов
  `web/*.js`. В браузере проверьте график, точность и стрелки замеров,
  журнал воркера, экран `/view`, вход и скачивание резервных кодов.
- `python3 qa/smoke_linux.py` — установка текущего дерева без root
  в новый временный префикс и проверка loopback HTTP с имитацией майнера.
- Физические GPU сторонних пользователей, реальные шары и выплаты
  подтверждаются отдельно. Тестовый процесс ничего не майнит.
- Проверьте простой, учёт активного времени, окно DevFee, паузу
  владельца, недоступность политики и остановку по термозащите.
  Для панели владельца проверьте веб-привязку 2FA и публичный флаг
  политики по HTTPS. Только аутентифицированный сеанс может менять флаг.
- Публикуйте архив и его SHA-256 в одной записи официального релиза,
  рядом с [условиями DevFee](releases/0.8.0-rc.1.md). Не копируйте в
  архив настройки, идентификаторы, кошельки, ключи и журналы Atlas.
  Не заменяйте архивы прошлых выпусков и не меняйте атрибуцию
  сторонних компонентов.
