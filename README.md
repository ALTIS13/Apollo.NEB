# <img src="web/brand.svg" width="34" alt=""> Apollo.NEB

Панель для добычи NEB Mainnet на Linux и управления Linux-нодами с Windows.

[Скачать выпуск](https://github.com/ALTIS13/Apollo.NEB/releases) · [Настройка и обновление](docs/onboarding-and-distribution.md) · [Что нового](docs/releases/0.9.0-rc.1.md)

| Система | Что скачать |
| --- | --- |
| Linux | Обычный архив, либо пакет x64 для ядра 6.6 или 6.12 |
| Windows x64 | ZIP контроллера Linux-нод, Python 3.10+ x64 |

Скачайте пакет и его файл .sha256 из одного выпуска. Сверьте сумму перед распаковкой.
На Linux запустите ./install.sh --run без sudo. На Windows откройте Apollo.NEB.cmd.
Панель откроется по адресу <http://127.0.0.1:18763/>. Задайте пароль при первом
запуске и включите 2FA в разделе **Защита входа**.

Linux поддерживает AMD/OpenCL, NVIDIA/CUDA и совместимый майнер с ручной настройкой.
Укажите свой адрес NEB Mainnet и запустите воркер из панели. На Windows подключите
Linux-ноду через раздел **Ноды**.

**DevFee — 1,1% активного времени добычи.** Состояние видно в панели.

Раздел **Обновления** позволяет выбрать основной или тестовый канал и проверить
пакет для системы. [Экран /view](http://127.0.0.1:18763/view) показывает сводные метрики
без входа. [Проверки выпуска](docs/release-checks.md) · [Откат](docs/onboarding-and-distribution.md#откат)
