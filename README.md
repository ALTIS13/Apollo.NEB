# <img src="web/brand.svg" width="34" alt=""> Apollo.NEB

**Self-hosted Linux GPU mining dashboard for NEB (Neural Engine Byte).**

Панель управляет зарегистрированными майнерами AMD/OpenCL и NVIDIA/CUDA:
показывает хешрейт, мощность, температуры и историю, останавливает воркер
при перегреве и принимает группы команд для своего парка нод (fleet).
В комплекте — настройка NEB Wallet и вход с TOTP. Это самостоятельная
установка, не требующая доступа к частной ферме Atlas.

## Перед установкой: DevFee 0,5%

В официальном пакете **0.7.1-rc.1** DevFee обязательна: **0,5% времени
активной добычи**, а не 0,5% монет, баланса или выплат. Кнопки и настройки
для отключения DevFee в этом выпуске нет. Если это условие вам
не подходит, не устанавливайте этот пакет.

- До явного запуска воркера ни добыча, ни DevFee не активны. Воркер
  начинает с вашего адреса. После 59 700 секунд (около 16 ч 35 мин)
  учтённой работы на вашем адресе предусмотрено окно до 300 секунд
  (5 минут) на публичный адрес DevFee, после чего воркер возвращается
  на ваш адрес при штатном завершении окна. Время учитывается отдельно
  для каждого воркера; простой и остановка не начисляют время.
- Получатель — отдельный публичный [адрес из developer-support.json](developer-support.json):
  `neb1plksgdvyzznpa5xx86r6hs7cup43dcv9v0wthsx4ggfxyprujl8q6lxt3x`.
  Для переключения пулу передаётся публичный адрес. Ключи, seed-фразы
  или существующие выплаты пользователя не передаются и не списываются.
- Условия действуют и при запуске из терминала, и в пользовательской
  службе systemd, включая совместимый `custom`-адаптер. Остановки,
  пределы температуры и ошибки могут сократить или прервать окно.
  0,5% — правило учёта времени процесса, не гарантия доли принятых
  шар или дохода. Майнер и пул могут иметь собственные комиссии.

Это условие относится к официальному **0.7.1-rc.1**; ранее опубликованные
архивы не заменяются и сохраняют свои условия.

## Установка на Linux

Нужен обычный выделенный пользователь Linux, Python 3.10+ и
`sha256sum`. Для запуска воркеров нужен Linux 5.3+ с `pidfd`;
для встроенных пакетов майнеров — Linux x86-64 с glibc 2.35+ и
установленный драйвер AMD или NVIDIA. Установщик не требует `sudo`,
не меняет драйверы, сеть и права доступа к устройствам, сам не
скачивает майнер и не запускает добычу.

1. Откройте [официальные релизы по HTTPS](https://github.com/ALTIS13/Apollo.NEB/releases).
   В записи **v0.7.1-rc.1** скачайте `apollo-neb-0.7.1-linux.tar.gz` и
   `apollo-neb-0.7.1-linux.tar.gz.sha256` в один каталог. Нужны именно
   эти файлы релиза, а не автоматически сформированный GitHub Source code.
2. Проверьте контрольную сумму **до распаковки**. Если проверка не
   завершилась с `OK`, не запускайте установщик. SHA-256 проверяет
   соответствие архиву из официального релиза; это не отдельная подпись.

   ```sh
   sha256sum --check --strict apollo-neb-0.7.1-linux.tar.gz.sha256
   ```

3. Распакуйте проверенный архив в новый каталог и запустите панель:

   ```sh
   setup_dir=$(mktemp -d) &&
     tar -xzf apollo-neb-0.7.1-linux.tar.gz -C "$setup_dir" --strip-components=1 &&
     (cd "$setup_dir" && ./install.sh --run)
   ```

   Для запуска фоновой пользовательской службы вместо `--run`
   выберите `--service` (нужен systemd с пользовательской сессией и
   стандартными путями установки). Воркеры не запускаются даже при
   перезапуске панели или службы. Работу после выхода пользователя
   определяют настройки Linux.

## Первый запуск

1. Задайте пароль панели в терминале. Откройте
   <http://127.0.0.1:18763> и войдите. Чтобы включить 2FA, нажмите
   **Защита входа**: повторите пароль, добавьте локально сгенерированный
   QR-код в приложение-аутентификатор или введите секрет вручную и
   подтвердите код. Сохраните одноразовые резервные коды офлайн:
   панель показывает их только после подключения.
2. В **Профиле пула** укажите существующий публичный адрес NEB
   Mainnet или откройте **Кошельки**. По вашему запросу панель
   загрузит и проверит официальный NEB Wallet. Создайте кошелёк с
   отдельным паролем и скачайте зашифрованную копию `.neb`. Храните
   файл и пароль раздельно: без пароля панель не восстановит кошелёк.
   Переводы и выдача открытых ключей в браузере не поддерживаются.
3. Откройте **Воркеры → Добавить GPU**. Выберите проверенный пакет
   майнера, дождитесь проверки, добавьте подходящие PCI-устройства.
   Затем запустите один воркер или выбранную группу отдельной командой.
   В группе результат отображается по каждому воркеру.
4. Для второго Linux-хоста откройте **Ноды** и создайте одноразовый
   код подключения. На другом хосте сначала установите Apollo.NEB,
   затем при остановленной локальной панели выполните показанную
   команду `apollo-neb node-pair` и введите код по запросу в терминале.
   Если команда не найдена, используйте `~/.local/bin/apollo-neb`.
   Центр видит состояние и может запускать/останавливать только уже
   настроенные воркеры. Произвольных команд и автоматического повтора
   при неизвестном исходе нет. Отзыв доступа не останавливает майнер.

Для удалённого доступа оставьте службу на loopback и используйте, например,
`ssh -L 18763:127.0.0.1:18763 user@your-host`. При подключении ноды через
такой туннель нужен явный `--allow-loopback`. Для обратного прокси
используйте доверенный сертификат HTTPS. Сначала включите TOTP через
локальный вход, затем на остановленной панели задайте точный адрес
`~/.local/bin/apollo-neb configure --origin https://neb.example`.
Не открывайте прямой HTTP наружу.

## Майнеры и границы доверия

| Адаптер | Назначение |
| --- | --- |
| `suprminer-opencl` | AMD: PCI-адрес, однозначное соответствие OpenCL и доступные показания температуры. |
| `suprminer-cuda` | NVIDIA: проверенная привязка PCI ↔ CUDA UUID и доступные показания температуры. |
| `custom` | Доверенный foreground-бинарник с буквальным массивом аргументов и обязательными `{pool}` и `{wallet}`; для GPU — `{device}`. |

Встроенные профили опираются на [инструкцию Suprnova](https://neb.suprnova.cc/StartMining.html)
и [релизы Suprminer](https://github.com/ocminer/suprminer/releases).
Совместимость каждой модели GPU, драйвера и пула не гарантирована.
Для ручной установки используйте [образцы конфигурации](examples/)
и `~/.local/bin/apollo-neb devices`. Кастомный майнер работает с правами
пользователя Linux, не в аппаратной песочнице. Он должен использовать
переданные публичные адреса и оставаться в своей группе процессов.
Не храните посторонние ключи под тем же пользователем.

При перегреве или потере обязательного датчика GPU-воркер
останавливается. У custom CPU нет GPU-термозащиты; Portable не
меняет лимит питания. Если телеметрия не поступает, панель показывает
пропуск, а не ноль. Маршрут ручной конфигурации и форматы аргументов
описаны в [инструкции](docs/onboarding-and-distribution.md).

## Обновление и проверка

В блоке **Релизы** нажмите **Проверить релиз** или выполните
`~/.local/bin/apollo-neb upgrade`. Перед применением остановите
панель и сохраните приватную копию настроек и состояния
(`~/.config/apollo-neb`, `~/.local/state/apollo-neb` или ваши XDG-пути).
Установка — только явной командой `~/.local/bin/apollo-neb upgrade --apply`;
для установленной пользовательской службы со стандартными путями
можно добавить `--service`. CLI проверяет SHA-256 архива по метаданным
официального релиза. Старый код нельзя запускать поверх новой базы
входа без соответствующей резервной копии.

[Проверки выпуска](docs/release-checks.md) используют локальный API
и имитацию процесса майнера. Они не подтверждают реальные шары,
размер дохода, выплаты пула или работу на всех физических GPU.
