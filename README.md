## Установка

Нужны обычный пользователь Linux, Python 3.10+, Linux 5.3+ с `pidfd` и установленный драйвер для вашей GPU. Для встроенных майнеров нужны x86-64 и glibc 2.35+.

Скачайте архив и файл `.sha256` с одной страницы выпуска. Проверьте сумму перед распаковкой.

```sh
sha256sum --check --strict apollo-neb-0.8.0-linux.tar.gz.sha256 &&
  tar -xzf apollo-neb-0.8.0-linux.tar.gz &&
  (cd Apollo.NEB-0.8.0 && ./install.sh --run)
```

1. Задайте пароль в терминале и откройте <http://127.0.0.1:18763/>.
2. Включите 2FA в разделе **Защита входа** и скачайте резервные коды.
3. Выберите пул, настройте свой кошелёк NEB Mainnet и добавьте воркеры. Майнинг начнётся по вашей команде.

Для фоновой службы используйте `./install.sh --service` в пользовательской сессии systemd. Для удалённого доступа используйте SSH-туннель или HTTPS с 2FA.
