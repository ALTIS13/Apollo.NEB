# <img src="web/brand.svg" width="34" alt=""> Apollo.NEB

Панель добычи NEB Mainnet для Linux-нод и приложение мониторинга для Windows.

[Скачать выпуск](https://github.com/ALTIS13/Apollo.NEB/releases) · [Настройка и обновление](docs/onboarding-and-distribution.md) · [Что нового](docs/releases/0.9.2.md)

| Система | Что скачать |
| --- | --- |
| Linux | Обычный архив, пакет x64 для ядра 6.6 или 6.12, либо [загрузочный образ x64 UEFI](docs/onboarding-and-distribution.md#загрузочный-образ-linux), если он приложен к выпуску |
| Windows x64 | Apollo.NEB Desktop для мониторинга GPU и фермы. ZIP контроллера требует Python 3.10+ x64 |

Скачайте пакет и его файл .sha256 из одного выпуска. Сверьте сумму перед распаковкой.
На Linux запустите `./install.sh --run` без sudo. На Windows распакуйте
нужный ZIP и откройте `Apollo.NEB.Desktop.exe` или `Apollo.NEB.cmd` для контроллера.
Локальная веб-панель доступна по адресу <http://127.0.0.1:18763/>.

Linux поддерживает AMD/OpenCL, NVIDIA/CUDA и совместимый майнер с ручной настройкой.
Укажите свой адрес NEB Mainnet и запустите воркер из панели.
Привязка ноды, версии и обновления доступны в разделе **Ноды**.

**DevFee — 1,1% активного времени добычи.** Состояние видно в панели.

Раздел **Обновления** позволяет выбрать основной или тестовый канал и проверить
совместимые версии и список изменений выбранного пакета. Панель открывается
в режиме просмотра. Для операций используйте **Разблокировать управление**.
